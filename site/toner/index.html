The corpus, and why it isn't SPF this time

Toner is almost never sold with an SPF claim, so this corpus uses the FDA's other monograph route to an OTC drug label: salicylic acid, an acne-treatment active. All 7 products here are liquid toners with a formulated cosmetic vehicle, filed the same way the SPF foundations are — a manufacturer's own declaration to the FDA, never a retailer listing.

Two populations of "toner" turned out not to be comparable and are excluded rather than blended in: plain witch-hazel astringents (T.N. Dickinson's, CVS Health, Equate) declare only witch hazel and alcohol, with no formulated vehicle to compare; and Stridex Maximum's FDA filing is for pre-saturated pads, not a pourable liquid, despite sharing the "toner" branding. Both are the same kind of exclusion the foundation corpus already makes for powders and sticks: a different vehicle, not sourced more weakly.

The one rule this corpus actually triggers

5 of 7 toners are filed at the FDA acne monograph's 2.0% salicylic acid ceiling — which happens to equal the EU's leave-on concentration limit (Annex III entry 98, as amended by Regulation (EU) 2019/1966). The EU rule carries one condition the US monograph doesn't: a ban on use in preparations for children under 3. None of these labels carry that restriction.

Every product in this corpus declares its scent only as generic "fragrance"/"parfum" rather than naming an individual allergen, so the same EU-declarable fragrance-allergen check already run for the foundation corpus finds zero matches here — a real finding, not a skipped computation. A full EU Annex II general-prohibition sweep, like the one run for the foundation corpus, has not yet been done for this category; see the corpus's known limits.

  • Monograph-only inclusion is a selection bias, the same shape as foundation's SPF-only rule: it excludes non-drug toners (Kiehl's, Clinique, Paula's Choice, most prestige lines), which have no primary filing and are excluded rather than sourced more weakly. This corpus is therefore budget/mass-tier-heavy; no prestige-counter brand carries a qualifying filing.
  • The FDA's astringent monograph (plain witch hazel: T.N. Dickinson's, CVS Health, Equate, and Biore Witch Hazel Pore Clarifying Toner) also produces FDA-filed toner labels, but those products declare only witch hazel and alcohol as ingredients with no formulated vehicle -- there is nothing to cross-brand-compare at the inactive-ingredient level, so they are excluded here as a different formulation type, not sourced more weakly (mirrors the foundation corpus excluding powders/sticks as 'different vehicle, not comparable').
  • Biore Witch Hazel Pore Clarifying Toner (Kao USA) has a live DailyMed web page (setid 6edb3b74-e694-fe90-e053-2991aa0ab8ea) but no entry in the DailyMed SPL REST API this project's fetch tool uses -- the underlying XML is not retrievable through the pipeline this project requires, so it is excluded on sourcing-mechanics grounds as well as the vehicle-type exclusion above.
  • Stridex Maximum's SPL (setid a3b16d52-76a5-438b-a120-bb59ce062cc1) filed under the same 'toner' branding is not a pourable liquid: its packaging section lists jars of 55/70/90/110 pre-saturated pads, not a fluid ounce/mL fill. Same dosage-form exclusion as powders/sticks in the foundation corpus -- excluded as a different vehicle, not sourced more weakly.
  • An FDA filing is verbatim what the manufacturer submitted, including typos and inconsistent separator characters. Corrections are recorded per-ingredient in the normalization layer, never silently.
  • Burt's Bees Natural Acne Solutions Clarifying Toner's SPL label has an effective date of 2010-08-16, the oldest filing in any corpus this project uses; DailyMed has no newer version indexed, so this is treated as the current filing rather than superseded.
